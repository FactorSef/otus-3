# Найденные ошибки

Найдены разбором кода. Баги B1–B12 подтверждены тестами `test.failing` в `tests/`. Статус — **открыто**, если не указано иное.

## Парсинг

### B1. Короткий HEX `#fff` не распознаётся
[src/constants.ts:3-5](../src/constants.ts#L3-L5) — `([a-f\d]{2}){3,4}` требует пары символов, поэтому 3-символьная форма невалидна, а ветка `value.length === 3` в `parseHEX` недостижима. 4-символьная `#rgba` тоже не поддерживается.

### B2. Ветка разбора 3-символьного HEX сломана
[src/index.ts:150-154](../src/index.ts#L150-L154) — `parseInt(value[0])` парсит символ как десятичное число (`parseInt('f') → NaN`), затем числа передаются в `hexSegmentParser`, который ждёт строки. Нужно передавать сами символы: `[r, r, g, g, b, b]` из строк.

### B3. Нулевая прозрачность игнорируется
[src/index.ts:162](../src/index.ts#L162), [178](../src/index.ts#L178), [206](../src/index.ts#L206) — `a = 0` по умолчанию + `if (a)` → `rgba(0,0,0,0)` даёт `a = 1`. Нужен дефолт `a = 1` / проверка на `undefined`.

### B4. Синтаксис CSS Color Level 4 и проценты не поддерживаются в RGB/HSL
[src/index.ts:161](../src/index.ts#L161), [src/constants.ts:8-13](../src/constants.ts#L8-L13) — `parser` вырезает пробелы, `/`, `%`, `-`:
- `rgb(255 0 0 / 50%)` → одна склеенная цифра;
- `rgb(100%, 0%, 0%)` → `100, 0, 0`;
- alpha в процентах (`hsla(0,0%,0%,50%)`) → `50`, обрезается до 1;
- отрицательный hue теряет знак (обработка `h < 0` в `parseHSL` бесполезна).

### B5. Серые цвета в HWB почти чёрные
[src/index.ts:212-214](../src/index.ts#L212-L214) — при `w + b >= 1` значение `w / (w + b)` (0..1) ограничивается `0..255`, но не умножается на 255. Должно быть `Math.round(g * 255)`.

### B6. Регэксп HWB принимает `hw(`
[src/constants.ts:15](../src/constants.ts#L15) — `^hwb?\(` делает `b` необязательной.

### B7. Невалидный тип при создании из массива
[src/index.ts:34](../src/index.ts#L34) — без `type` `initialValue = undefined`, цвет парсится как RGB (с предупреждением), но `isValid === false`.

## Вывод

### B8. Whiteness/blackness только 0 или 100
[src/utils.ts:69-70](../src/utils.ts#L69-L70) — `Math.round` применяется к значению 0..1 до умножения на 100. Нужно `Math.round(min * 100)`.

### B9. `toHwbString()` без alpha выводит `hsl(`
[src/index.ts:261](../src/index.ts#L261) — опечатка префикса, должно быть `hwb(`.

### B10. Alpha в HEX некорректен
[src/index.ts:229](../src/index.ts#L229) — `segmentToHex(this.a)` при `a = 0.5` даёт `"0.8"`; нужно `Math.round(this.a * 255)`. Также дробные `r/g/b` (например, из `rgb(10.5, ...)`) дают дробный hex — `segmentToHex` не округляет.

### B11. Hue = NaN для ахроматических цветов
[src/utils.ts:39](../src/utils.ts#L39) — начальное `hue = NaN` не заменяется при `d === 0`, итог `hsl(NaN, 0%, 50%)` / `hwb(NaN ...)`. Нужно выводить `0`.

### B12. Плавающая погрешность в `alpha()`
[src/index.ts:284](../src/index.ts#L284) — `a * 100` без округления: `0.07 * 100 = 7.000000000000001`, `0.57 * 100 = 56.99999999999999`.
