# Исправление бага B3

Исправь баг B3 из `memory-bank/bugs.md`: нулевая прозрачность игнорируется, и `rgba(0, 0, 0, 0)` превращается в цвет с `a = 1`.

Причина: в `parseRGB`, `parseHSL` и `parseHWB` ([src/index.ts](../src/index.ts)) альфа по умолчанию равна `0`, а записывается только при условии `if (a)`, поэтому `0` отбрасывается.

## Шаги
1. В трёх методах замени значение по умолчанию на `a = 1`. Альфу записывай, если это конечное число (`Number.isFinite(a)`), вместо проверки `if (a)`.
2. Внутренние вызовы `parseHSL([...])` без альфы теперь сбросят её в `1`. Такие вызовы должны передавать `this.a` явно.
3. Покрой тестами: `rgba(0, 0, 0, 0)`, `hsla(0, 0%, 0%, 0)`, `hwb(0 0% 0% / 0)` и `new Color([0, 0, 0, 0], 'rgb')` дают `a === 0`, а цвета без альфы дают `a === 1`.
4. Отметь B3 исправленным в `memory-bank/bugs.md`.
