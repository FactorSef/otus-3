# Добавление нового функционала: hue-rotate

Добавь в класс `Color` метод поворота оттенка `hueRotate`. Угол задаётся двумя параметрами: значением и единицей измерения (`deg`, `grad`, `rad`, `turn`).

Перед началом прочитай [CLAUDE.md](../CLAUDE.md) и [memory-bank](../memory-bank/) и соблюдай раздел «Правила выполнения задачи».

## Требования

### Сигнатура

```ts
type AngleUnit = 'deg' | 'grad' | 'rad' | 'turn';

hueRotate(value: number, unit: AngleUnit = 'deg'): Color;
```

- Метод **изменяет текущий объект и возвращает `this`**, как `alpha(value)`. Так вызовы можно объединять в цепочку.
- Тип `AngleUnit` экспортировать, чтобы пользователи могли его использовать.

### Семантика

Поворот оттенка в модели **HSL**: `h' = (h + угол) mod 360`. Насыщенность, светлота и прозрачность не меняются.

Не используй матрицу CSS-фильтра `filter: hue-rotate()`. Она даёт другой результат и меняет светлоту цвета.

### Перевод единиц в градусы

| Единица | Формула | Полный оборот |
|---|---|---|
| `deg` | `value` | 360 |
| `grad` | `value * 0.9` | 400 |
| `rad` | `value * 180 / Math.PI` | 2π |
| `turn` | `value * 360` | 1 |

Результат нормализовать в диапазон `[0, 360)` с учётом отрицательных углов и углов больше оборота: `((deg % 360) + 360) % 360`.

### Граничные случаи

- **Серые цвета** (`s = 0`, включая белый и чёрный) у поворота не меняются. Не допускай появления `NaN` (см. B11 в [bugs.md](../memory-bank/bugs.md)).
- **Нечисловое или бесконечное `value`** (`NaN`, `Infinity`): вывести `console.warn('[Color]: ...')` и вернуть `this` без изменений.
- **Неизвестная единица**: вывести `console.warn` и считать значение градусами. Так уже сделано в `initByArray`, где по умолчанию используется RGB.
- **Точность.** `rgbToHsl` округляет результат до целых, и после нескольких поворотов подряд цвет будет «уплывать». Для поворота нужна HSL без округления: добавь отдельную функцию или параметр, но не меняй поведение `toHslString`.
- **Прозрачность** сохраняется. Не передавай `a` через `parseHSL`, потому что у него ошибка с `a = 0` (B3). Меняй только `r`, `g`, `b`.

### Где размещать код

- Тип `AngleUnit` и функцию `angleToDegrees(value, unit)` положить в [src/utils.ts](../src/utils.ts). Коэффициенты единиц при желании вынести в [src/constants.ts](../src/constants.ts).
- Метод `hueRotate` разместить в [src/index.ts](../src/index.ts) после `alpha()`.
- Каждый добавленный фрагмент обернуть в `//#region hue-rotate` … `//#endregion hue-rotate`.

## Ожидаемые результаты (для тестов)

| Исходный цвет | Вызов | Результат `toHexString()` / `toRgbString()` |
|---|---|---|
| `#ff0000` | `hueRotate(120)` | `#00ff00` |
| `#ff0000` | `hueRotate(120, 'deg')` | `#00ff00` |
| `#ff0000` | `hueRotate(200, 'grad')` | `#00ffff` |
| `#ff0000` | `hueRotate(Math.PI, 'rad')` | `#00ffff` |
| `#ff0000` | `hueRotate(0.5, 'turn')` | `#00ffff` |
| `#ff0000` | `hueRotate(-120)` | `#0000ff` |
| `#ff0000` | `hueRotate(480)` | `#00ff00` |
| `#ff0000` | `hueRotate(1, 'turn')` | `#ff0000` |
| `#ff0000` | `hueRotate(0)` | `#ff0000` |
| `#808080` | `hueRotate(90)` | `#808080` |
| `rgba(255, 0, 0, 0.5)` | `hueRotate(120)` | `rgba(0, 255, 0, 0.5)` |
| `#ff0000` | `hueRotate(NaN)` | `#ff0000` + предупреждение |
| `#ff0000` | `hueRotate(60).hueRotate(60)` | `#00ff00` (цепочка) |
| любой | 36 × `hueRotate(10)` | исходный цвет (нет накопления ошибки) |

Также проверить `angleToDegrees` отдельно: `(400, 'grad') → 360`, `(0.25, 'turn') → 90`, `(Math.PI / 2, 'rad') → 90`.
