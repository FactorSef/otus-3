# Добавление нового функционала: hue-rotate

Добавь в класс `Color` метод `hueRotate`, который поворачивает тон (hue) цвета на заданный угол. Угол задаётся двумя параметрами: **значением** и **единицей измерения** — `deg`, `grad`, `rad`, `turn` (как `<angle>` в CSS Values Level 4).

Перед началом прочитай `CLAUDE.md` и `memory-bank/` и соблюдай раздел «Правила выполнения задачи».

## Требования к API

```ts
import Color, { AngleUnit } from '@factor-sef/colorful';

const color = new Color('#ff0000');

color.hueRotate(120);                    // deg по умолчанию → '#00ff00'
color.hueRotate(0.5, AngleUnit.Turn);    // 180°
color.hueRotate(Math.PI, 'rad');         // строковый литерал тоже допустим
color.hueRotate(-100, AngleUnit.Grad);   // отрицательный угол — поворот в обратную сторону

color.hueRotate(30).alpha(50);           // метод возвращает this, цепочка работает
```

- Сигнатура: `hueRotate(value: number, unit: AngleUnit | \`${AngleUnit}\` = AngleUnit.Deg): Color`.
- Метод **изменяет текущий экземпляр** и возвращает `this`, как это уже делает `alpha(value)`. Для получения нового цвета пользователь пишет `new Color(color).hueRotate(...)`.
- Альфа-канал не меняется.
- Любой угол допустим, результат приводится к 0..360: `hueRotate(360)` и `hueRotate(720)` ничего не меняют, `hueRotate(-120)` равносилен `hueRotate(240)`.

## Единицы измерения

Заведи **строковый enum** (правило из `CLAUDE.md`) в [src/constants.ts](../src/constants.ts):

```ts
export enum AngleUnit {
	Deg = 'deg',
	Grad = 'grad',
	Rad = 'rad',
	Turn = 'turn',
}
```

Перевод в градусы:

| Единица | Полный круг | Формула в градусы |
|---|---|---|
| `deg` | 360 | `value` |
| `grad` | 400 | `value * 0.9` |
| `rad` | 2π | `value * 180 / Math.PI` |
| `turn` | 1 | `value * 360` |

Реэкспортируй enum из [src/index.ts](../src/index.ts) (`export { AngleUnit } from './constants';`), чтобы им можно было пользоваться снаружи. Тип параметра `AngleUnit | \`${AngleUnit}\`` оставляет возможность передать обычную строку `'rad'` из JavaScript без импорта enum.

## Алгоритм

Поворот тона выполняется в модели **HSL**: RGB → HSL → `h + угол` → RGB. Именно так понимают «hue rotation» цветовые библиотеки, а насыщенность и светлота при этом сохраняются. Матрица CSS-фильтра `filter: hue-rotate()` для этого не подходит: она приближённая и меняет светлоту и насыщенность, поэтому результат не совпадёт с тем, что покажет `toHslString()`.

1. Переведи угол в градусы и нормализуй его к 0..360.
2. Получи HSL текущего цвета **без округления**. Сейчас `rgbToHsl` в [src/utils.ts](../src/utils.ts) округляет h/s/l до целых, и после поворота на 0° цвет может сдвинуться на единицу канала. Раздели функцию на две:
   - `rgbToHslRaw(r, g, b)` — текущее вычисление без `Math.round`, возвращает `[h°, s 0..1, l 0..1]`;
   - `rgbToHsl(r, g, b)` — прежняя публичная функция, теперь вызывает `rgbToHslRaw` и округляет результат. Её поведение не должно измениться.
3. Если у цвета нет тона (`r === g === b`, насыщенность 0; сейчас в этом случае hue = `NaN`, см. `bugs.md` B11), верни `this` без изменений: поворот серого цвета ничего не меняет.
4. Иначе запиши новый цвет через существующий `parseHSL([h + angle, s * 100, l * 100])`. Он сам нормализует hue и переводит его в `r/g/b`. Альфу не передавай: из-за ошибки B3 значение `0` проигнорировалось бы, а так `this.a` просто останется прежним.

### Вспомогательные функции (`src/utils.ts`)

```ts
export function angleToDegrees(value: number, unit: AngleUnit | `${AngleUnit}`): number;
export function normalizeHue(degrees: number): number; // ((d % 360) + 360) % 360
```

### Обработка некорректного ввода

Действуй в стиле проекта: без исключений, через `console.warn('[Color]: ...')`.

- `value` не конечное число (`NaN`, `Infinity`, не `number`) → предупреждение, цвет не меняется, возвращается `this`.
- `unit` не входит в `AngleUnit` → предупреждение, единица считается `deg`.
