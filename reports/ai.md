# ИИ-инструмент

Инструкции в проекте написаны для **Claude Code** — агента для программирования от Anthropic. Здесь он работал как расширение VS Code на модели **Claude Opus 5.5**.

## Что умеет Claude Code

- Читает, ищет и редактирует файлы проекта.
- Запускает команды в терминале (`npm`, `jest`, `tsc`, `git`) и учитывает их вывод.
- Решает задачи в несколько шагов: изучает код, планирует, меняет его, проверяет тестами и сборкой.
- Спрашивает разрешение на действия по настроенному режиму прав.

## Как инструмент получает инструкции

| Файл | Как используется |
|---|---|
| `CLAUDE.md` | Загружается в контекст автоматически в начале каждой сессии. Содержит описание проекта, команды, правила кода и правила выполнения задач: план до изменений, `//#region`, тесты. |
| `memory-bank/*.md` | На них ссылается `CLAUDE.md`, агент читает их перед работой: `about.md` — описание и API, `structure.md` — устройство кода, `bugs.md` — известные ошибки. |
| `instructions/NN.md` | Постановка задачи. Передаётся в промпт через упоминание `@instructions/NN.md`, при этом содержимое файла прикладывается к сообщению. |

Правила из `CLAUDE.md` действуют во всех задачах, поэтому в `instructions/*.md` их можно не повторять: достаточно цели, контекста и шагов.
